变异关联判读核对

这是一份核对问卷：请阅读每篇摘要，判断摘要对指定变异（rsID）给出的结论。结果用来检验自动判读的准确度，页面不显示任何自动判读的答案。

共两部分，约 2 小时，可以分几次做完。每次选择都会自动保存到云端，同时在本机留一份；中途关闭页面不会丢失。
第一部分 · 判断一对关系（120 题）：题目给出一个变异和一个疾病或性状，请按摘要的说法选一项。
第二部分 · 查漏（30 篇）：列出摘要提到的全部变异，请逐个判断摘要是否报告了它与任何疾病或性状存在有统计学支持的关联。

第一部分的四个选项

有关联摘要报告这个变异与这个疾病/性状有关联（显著、风险升高或降低、与表型相关等），包括只在某个亚组或某种遗传模型下成立的关联。 报告无关联摘要明确说这个变异与这个疾病/性状没有关联、差异不显著，或者未能重复。 无结论这对关系在摘要里被研究或提到，但摘要没有就它给出有无关联的结论（只报告频率、只说"进一步研究"、结论含糊）。 不相关摘要并没有研究这个变异与这个疾病/性状的关系（变异或疾病对不上，属于提取错误）。

例："rs1234 的 T 等位基因与 2 型糖尿病风险升高相关（OR 1.3，P = 0.002）" → 有关联。

例："rs1234 在病例和对照间的分布无显著差异" → 报告无关联。

例：摘要研究的是 rs1234 与骨密度，题目问的是 rs1234 与骨关节炎 → 不相关。

判断以摘要正文为准，不需要查原文或别的资料；拿不准时选你认为最接近的一项，可在备注里写一句。疾病名称和变异在摘要中已用底色标出（自动标注，可能有遗漏）。

第二部分

对列出的每个变异选"有"或"无"：有 = 摘要报告它与某个疾病或性状存在有统计学支持的关联（任一疾病即可）；无 = 摘要只提到它、报告阴性，或没有给出结论。
